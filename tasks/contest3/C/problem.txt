У вас есть массив a из n элементов и q запросов на сумму на отрезке от l до r.
В первой строке вводятся числа n и q.
В следующей строке вводятся n чисел — элементы массива.
В следующих q строках вводятся l и r, причём l <= r <= n.
Гарантируется, что n < 10<sup>5</sup>, q < 10<sup>5</sup>, a[i] < 10<sup>5</sup>.
